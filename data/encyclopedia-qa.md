# 도감 설명·계급 표식 보완 — 2026-10-14

## 이번 변경

- 관련 정적 JS와 데이터에 같은 배포 버전을 전달합니다. 기존 로더는 고정 주소의 파일을 각각 캐시할 수 있었고, 업적 모듈도 게임 로직을 별도로 불러왔습니다. 새 설명 코드와 이전 로직이 섞일 가능성을 제거했습니다. 사용자 환경에서 발생한 원인이 캐시였는지까지 직접 확인한 것은 아닙니다.
- 설명 표식에 클릭 핸들러를 직접 연결했습니다. 기존의 데이터 표식 유무만 검사하던 테스트를 보완하여 상위 50곳을 포함한 143개 표식의 클릭 핸들러가 설명창을 여는지 검사합니다.
- 기존에 생물 특징 없이 분류 위치만 말하던 기본 문구를 제거했습니다. 강·상강·아강·하강 96개 항목 모두에 별도로 작성한 한/영 주요 특징을 제공합니다. 이전의 연구 설명은 유지합니다.
- 대표 생물을 이름·학명으로 최대 4종 나열합니다. 현재 게임 수록종만 사용하며 가능한 한 속을 다르게 고릅니다. 수집한 생물을 먼저 보여 주고, 사진은 해당 분기의 후손만 사용합니다.
- 도감 오른쪽 중앙에 문 → 상강 → 강 → 아강 → 하강 → 목 순서의 범례를 추가했습니다. 각각 육각형·마름모·원·사각형·삼각형·오각형을 사용합니다. 기타 계급과 계급 없는 공통분기는 별도의 가지 기호를 사용합니다.
- 표식의 클릭 영역을 36px로 넓혔습니다. 이 크기는 계통수 배율이 적용되기 전의 크기입니다. 설명이 없는 목 등의 표식은 계급을 표시하지만 설명 버튼으로 작동하지는 않습니다.

생물 특징은 현생 구성원에 대한 요약이며 공통 조상의 복원으로 제시하지 않습니다. 모든 종에 해당하지 않는 형질은 ‘많은 종’, ‘보통’, ‘일부’ 등으로 범위를 구분합니다. 전통적인 Polychaeta·Aspidochirotacea 등의 이름은 현행 단일계통·계급과 다를 수 있음을 명시합니다. 기본 형태와 기능은 비교동물학 자료 및 기존에 연결한 분류군별 문헌을 바탕으로 작성했습니다. 참고 교육 자료에는 미시간대학교 동물박물관의 [포유류](https://animaldiversity.org/accounts/Mammalia/), [곤충](https://animaldiversity.org/accounts/Insecta/), [이매패류](https://animaldiversity.org/accounts/Bivalvia/), [두족류](https://animaldiversity.org/accounts/Cephalopoda/), [해면동물](https://animaldiversity.org/accounts/Porifera/), [극피동물](https://animaldiversity.org/accounts/Echinodermata/), [척삭동물](https://animaldiversity.org/accounts/Chordata/) 해설이 있습니다. 이 자료의 분류 계급을 게임에 일괄 적용한 것은 아닙니다.

## 사용자 QA

배포 후 새로고침하여 확인합니다.

1. 도감 → 계통수에서 동물계, 절지동물문·척삭동물문 등의 표식을 눌러 설명창이 열리는지 확인합니다.
2. 포유동물강·곤충강 등의 설명에 주요 특징과 대표 생물의 이름·학명이 보이는지 확인합니다.
3. 오른쪽 중앙 범례가 요청한 순서인지, 해당 계급의 표식과 모양이 일치하는지 확인합니다.
4. 한/영 전환과 위·아래·원형 배치에서 범례·설명·사진이 정상인지 확인합니다.

화면에서 쉽게 확인할 수 있는 배포 QA는 사용자가 진행합니다. 캐시 버전 전달, 클릭 핸들러, 대표 생물의 소속과 전체 분기 커버리지는 자동 검증합니다.
